图像分割（Image Segmentation）技术演进从传统方法到深度学习时代，再到Transformer与生成式模型的革命性突破。按技术范式划分阶段，逐代详解创新点、代表模型与性能影响：

## 前深度学习时代（1980s-2014）

### 阈值分割与边缘检测

- **技术方案**：

- - Otsu阈值法：自动选择最优灰度阈值分割前景/背景
  - Canny边缘检测：高斯滤波→梯度计算→非极大值抑制→双阈值连接

- **局限**：依赖人工设计特征，仅适用简单场景

### 图割算法（GraphCut, 2001）

- **创新点**：

- - 将图像建模为图结构（像素为节点，边权表示相似度）
  - 能量函数最小化（数据项+平滑项），用最大流/最小割求解

- **应用**：交互式分割（需用户标注前景/背景种子）

### 超像素分割（SLIC, 2010）

- **创新点**：

- - **K-Means聚类像素**：基于颜色+空间位置相似性生成紧凑超像素
  - **计算高效**：复杂度O(N)，适用于实时场景

- **影响**：为后续深度学习方法提供预处理基础

## 深度学习基础架构（2014-2017）

### FCN（Fully Convolutional Network, 2014）

- **革命性创新**：

- - **全卷积化**：替换CNN全连接层为卷积层 → 输出像素级分割热力图
  - **跳级连接**：融合浅层（高分辨率）与深层特征（高语义信息）

- **缺陷**：输出分辨率低（32倍下采样），边界粗糙

- **指标**：PASCAL VOC mIoU **62.2%**

### U-Net（2015）

- **创新点**：

- - **对称编解码结构**：编码器（下采样） + 解码器（上采样）
  - **特征拼接（Copy-Crop）**：跳跃连接传递位置细节

- **优势**：在医学影像（少量数据）表现优异

- **指标**：ISBI细胞分割竞赛冠军

### DeepLab v1（2014） & v2（2016）

- **v1创新**：

- - **空洞卷积（Dilated Convolution）**：扩大感受野（不增加参数量）

- **v2创新**：

- - **ASPP（空洞空间金字塔池化）**：并行多采样率空洞卷积 → 多尺度上下文捕获

- **指标**：PASCAL VOC mIoU **79.7%**

## 多尺度上下文优化（2017-2019）

### PSPNet（Pyramid Scene Parsing Network, 2017）

- **创新点**：

- - **金字塔池化模块**：不同网格尺度（1×1, 2×2, 3×3, 6×6）池化 → 融合全局语境

- **效果**：大幅提升大目标识别能力（如天空、建筑）

- **指标**：Cityscapes mIoU **81.2%**

### DeepLab v3+（2018）

- **创新点**：

- - **编解码增强**：Encoder（带ASPP的Xception）→ Decoder（浅层特征融合）
  - **深度可分离卷积**：降低计算量

- **性能**：PASCAL VOC mIoU **89.0%**（ResNet-101）

### DANet（Dual Attention Network, 2019）

- **创新点\**：

- - **通道注意力**：学习特征通道依赖关系
  - **位置注意力**：建模空间位置关联性

- **公式**：

- - 通道注意力：$A_c = \sigma(W_z \delta(W_v \mathbf{F}))$
  - 位置注意力：$A_p = \sigma(\mathbf{F}^T W_a \mathbf{F})$

- ***\*指标\****：Cityscapes mIoU ***\*81.5%\****

## 实例分割与实时分割突破（2017-2020）

### **Mask R-CNN（2017）**

- **创新点**：

- - **Faster R-CNN扩展**：添加并行掩码预测分支（FCN结构）
  - **RoIAlign**：双线性插值消除ROI Pooling量化误差 → 像素级定位精度↑

- **应用**：实例分割（区分同类别不同物体）

- ***\*指标\****：COCO mask AP ***\*37.1%\****

### ICNet（Image Cascade Network, 2018）

- **创新点**：

- - **多分辨率分支**：低分辨率（语义）→中分辨率（细节）→高分辨率（精修）
  - **级联特征融合**：逐步恢复细节

- **优势**：1024×2048图像达 **30 FPS**（Titan X GPU）

### BiSeNet（Bilateral Segmentation Network, 2018）

- **创新点**：

- - **双路结构**：

  - - **空间路径**：浅层网络保留空间细节（高分辨率）
    - **语境路径**：深层网络捕获语义信息（快速下采样）

- **效果**：Cityscapes 68.4% mIoU @ **105 FPS**

## Transformer与通用分割革命（2020至今）

### SETR（Swin Transformer for Segmentation, 2020）

- **创新点**：

- - **纯ViT主干**：图像切块→序列输入Transformer Encoder
  - **多解码器**：PUP（渐进上采样）或MLA（多尺度特征聚合）

- **指标**：ADE20K mIoU **50.3%**（首次超越CNN）

### MaskFormer（2021）

- **创新点**：

- - **统一分割范式**：将语义/实例/全景分割视为“掩码分类”问题

  - - 预测N个二值掩码 + 类别标签

  - **Transformer解码器**：可学习查询向量 → 生成掩码

- **指标**：COCO全景分割 PQ **57.8**（SOTA）

### Mask2Former（2022）

- **MaskFormer改进**：

- - **掩码注意力机制**：注意力计算限制在预测掩码区域 → 计算量↓90%
  - **多尺度特征优化**：高分辨率特征图辅助小目标分割

- **性能**：ADE20K mIoU **59.7%**

### Segment Anything Model（SAM, 2023）

- **创新点**：

- - **提示驱动分割**：支持点/框/文本提示 → 生成掩码
  - **大规模预训练**：SA-1B数据集（1100万图，10亿掩码）

- **零样本泛化**：无需微调，在未见类别达到专业模型水平

------

### 技术演进主线总结

1. **结构进化**：

```
FCN（基础）→ U-Net（医学）→ DeepLab（多尺度语境）→ Transformer（全局建模）
```

1. **任务扩展**：

```
语义分割 → 实例分割 → 全景分割 → 提示驱动通用分割
```

1. **精度与速度平衡**：

```
高精度（DeepLab）←→ 实时性（BiSeNet）←→ 通用性（SAM）
```

1. **训练范式革新**：

```
全监督（FCN）→ 弱监督（BoxSup）→ 零样本（SAM）
```

### 结论

图像分割历经四代技术跃迁：

1. **手工特征时代**（2000s）：图割、超像素 → 交互式分割
2. **深度网络基础期**（2014-2017）：FCN、U-Net、DeepLab → 自动化语义分割
3. **多尺度优化期**（2017-2020）：PSPNet、Mask R-CNN → 实例/全景分割
4. **Transformer通用期**（2020s）：SETR、SAM → 零样本开放世界分割

**SAM的出现标志着分割进入“基础模型”时代**，其零样本能力正推动自动驾驶、医学影像、AR/VR等领域的范式变革。
