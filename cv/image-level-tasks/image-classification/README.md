# 图像分类

从 LeNet（1989） 到 Vision Transformer（2020） 的关键突破，按技术范式划分为五大阶段，逐代详解创新点与性能影响：

## 前深度学习时代（1989-2011）

### LeNet（1989）

- **创新点**：首个卷积神经网络（CNN）
- **结构**：2层卷积 + 2层池化（Subsampling） + 全连接层
- **局限**：仅处理32×32小图（手写数字），无大规模训练能力



### SIFT + Bag of Words（1999-2006）

- 技术方案：

- 1. SIFT提取局部特征（旋转/尺度不变）
  2. K-Means聚类生成视觉词典（Visual Words）
  3. SVM分类器预测类别

- 问题：特征手工设计 → 泛化性差

- 指标：ImageNet 2010冠军方案仅73Top-5准确率

## 深度学习革命（2012-2014）

### AlexNet（2012）

- 革命性创新：

- - ReLU激活：替代Sigmoid，解决梯度消失
  - GPU并行训练：2张GTX 580训练大规模网络
  - Dropout：全连接层随机失活，抑制过拟合
  - Local Response Normalization：增强泛化性

- 性能突破：ImageNet Top-5准确率 84.7%（超越第二名10%）

### VGGNet（2014）

- **核心思想**：深度至上（Deepness Matters）

- **关键技术**：

- - **全3×3卷积堆叠**：2个3×3卷积=5×5感受野（参数量↓）
  - **16-19层深度**（VGG16/VGG19），证明深度提升性能

- **指标**：ImageNet Top-5 **92.7%**

- **影响**：成为迁移学习标准主干

### **Inception v1（GoogLeNet, 2014）**

- **创新点**：

- - **多分支结构**：并行1×1/3×3/5×5卷积 + 池化 → 多尺度特征融合
  - **1×1卷积降维**：压缩通道数（计算量降低3倍）
  - **辅助分类器**：缓解梯度消失（中间层损失监督）

- **指标**：ImageNet **93.3%** Top-5，仅500万参量（AlexNet的1/12）

## 深度优化与残差学习（2015-2017）

### **ResNet（2015）**

- **开创性设计**：**残差连接（Residual Connection）**

- **公式**：
  $$
  H(x)=F(x)+x
  $$
  F(x)为残差映射

- **核心思想**：让网络学习**差值**而**非完整映射** → 解决梯度消失

- **结构演进**：

- - **ResNet-50/101/152**：通过Bottleneck（1×1-3×3-1×1）降低计算量

- **指标**：ImageNet **96.4%** Top-5，首次超越人类（95%）

- **影响**：百万级网络层训练成为可能

#### 总结

ResNet-50的总结：

1. **第一层：** 7x7卷积 (stride=2, padding=3)，**输出通道64** -> BN -> ReLU -> 3x3 MaxPool (stride=2, padding=1) -> 特征图尺寸变为输入的 **1/4 (H/4, W/4)**。

2. **核心结构：** 使用 **Bottleneck 残差块**。每个块结构为：

3. - `路径A (Main Path)`: `Conv1x1 (降维) -> BN -> ReLU -> Conv3x3 (特征提取，可能stride=2) -> BN -> ReLU -> Conv1x1 (升维) -> BN`
   - `路径B (Shortcut Path)`: `Identity` 或 `Conv1x1 (stride=2用于下采样) -> BN` (当输入输出维度不匹配时)
   - **相加：** `路径A输出 + 路径B输出`
   - **激活：** `ReLU` (在**相加之后**应用)

4. **Stage结构：**

5. - 4个Stage，分别包含 3, 4, 6, 3 个 Bottleneck 块。
   - 每个Stage的**第一个块**负责下采样：**特征图尺寸减半 (H/2, W/2)，输出通道数翻倍**。
   - 该Stage内后续块的输入输出尺寸和通道数保持不变。
   - Stage之间通过第一个块的下采样连接，**没有独立的BN+ReLU隔开**。

6. **层数：** 总计 **50个带权重的层** (初始Conv + (3+4+6+3)*3 Conv + 最终FC)。

7. **结尾：** 全局平均池化 -> 全连接层 (分类输出)。

8. **核心创新：** **残差连接（恒等映射）** 是关键，解决了深度网络的退化问题，使训练极深网络可行。Bottleneck设计主要为了**降低计算复杂度**。

### DenseNet（2017）

- **核心创新**：**稠密连接（Dense Block）**

- - 第L层输入 = 前L-1层的所有特征图拼接
  - 增强特征复用，减少参数量

- **公式**：

- **优势**：参数量仅为ResNet的 **1/3**，精度更高

虽然**DenseNet** 在理论设计和参数效率上非常优雅，特征复用能力极强，梯度流动好，特别适合参数受限或对早期特征依赖强的场景（但在实践中，这些优势常被其高昂的内存成本抵消）。所以综合考虑后依然使用ResNet来当作特征提取器。

## 注意力机制引入（2018-2020）

### SENet（2018）

- 创新点：通道注意力（Squeeze-and-Excitation）

- - Squeeze：全局平均池化 → 通道统计描述
  - Excitation：全连接层学习通道权重（重要通道强化）

- 应用方式：作为模块嵌入ResNet（SE-ResNet）

- 指标：ImageNet **97.1%** Top-5

### EfficientNet（2019）

- 核心思想：复合缩放（Compound Scaling）

- - 联合优化深度/宽度/分辨率：
    $$
    depth:d={\alpha}^{\phi}
    $$

    $$
    width:w={\beta}^{\phi}
    $$

    $$
    depth:r={\gamma}^{\phi}
    $$

    （ϕ控制缩放系数，αβγ由网格搜索确定）

- **意义**：计算资源与精度的帕累托最优

Transformer颠覆（2020至今）

### Vision Transformer（ViT, 2020）

- **革命性设计**：**将图像视为序列**

- - 切分16×16图像块 → 展平为Patch Embeddings
  - 添加位置编码 → Transformer Encoder（与NLP同架构）

- **训练关键**：需**超大规模数据**（JFT-300M）

- **指标**：ImageNet **88.55%** Top-1（ViT-H/14）

将大图像打为N个小块，每个小块展开后通过线性层投影到d维度，加上可学习的位置编码后，然后叠加上一个分类token，然后按照标准的Transformer的Encoder部分计算，多层Encoder后，将分类token拿出来经过一个分类头后，完成分类。

Transformer架构主要关注以下一个点：Layers、隐藏层大小，MLP大小，Heads

给定上述参数，怎么计算参数量、访存比和计算量？

**缺点**：

1. **计算复杂度 (Scalability for Dense Predictions):**

2. - ViT 的自注意力机制是**全局**的（每个 Patch 关注图像中所有其他 Patch），其计算复杂度与 Patch 数量 `N` 的平方 `O(N²)` 成正比。
   - 对于**高分辨率图像**（如图像分割、目标检测、高清分类）或需要**密集预测**的任务，`N` 会非常大（例如，1024x1024 图像分 16x16 Patch，`N=4096`），导致计算量和内存消耗急剧增加，**难以扩展**到实际应用所需的分辨率。

3. **缺乏层级结构 (Lack of Multi-Scale Feature Maps):**

4. - ViT **从头到尾都是一个尺度**：输入的 Patch 尺寸恒定，输出的特征图尺寸也相同（忽略 `[class]` token）。
   - 这与 CNN 自然形成的**金字塔特征层级**（浅层小感受野高分辨率关注细节，深层大感受野低分辨率关注语义）相悖。这种多尺度特征对于密集预测任务（如检测、分割）至关重要，有助于模型理解从局部到全局的结构。

### **Swin Transformer（2021）**

- **改进ViT缺陷**：适应图像**层次化结构**与**高分辨率特征**

- **关键技术**：

- - **移位窗口（Shifted Window）**：

  - - Stage 1：4×4窗口局部注意力
    - Stage 2：窗口右移50% → 跨窗口信息交互

  - **层级降采样**：合并Patch → 多尺度特征图

- **优势**：

- - 计算复杂度从O(n²)降至**O(n)**（n为图像块数）
  - 目标检测/分割性能超越CNN

### ConvNeXt（2022）

- **核心思想**：**用CNN模拟Transformer优势**

- **关键改造**：

- - **大卷积核**：7×7深度卷积（仿Swin局部窗口）
  - **LayerNorm替代BN**：稳定训练
  - **GELU激活**：与Transformer一致

- **结论**：纯CNN在ImageNet达 ***\*87.8%\**** Top-1，匹敌Swin

## 技术演进主线总结

1. **特征提取方式**：

```
手工特征 → 卷积自动学习 → 注意力全局建模
```

1. **结构演进核心**：

```
增加深度（VGG） → 优化梯度（ResNet） → 多尺度（Inception） → 动态权重（SENet） → 序列建模（ViT）
```

1. **训练效率革命**：

2. - **数据**：ImageNet（2012）→ JFT-300M（ViT）
   - **硬件**：CPU → GPU → TPU
   - **优化**：SGD → AdamW + LayerNorm

## 当前方向（2023-2024）

1. **自监督学习**：MAE、MoCo v3 减少标注依赖
2. **多模态对齐**：CLIP（图文对比学习）驱动零样本识别
3. **神经架构搜索**：AutoML优化模型缩放策略

> 图像识别作为CV基石任务，其技术演进持续推动目标检测、分割等下游领域突破。**ViT与CNN的融合架构**（如Swin, ConvNeXt）仍是工业落地首选。
